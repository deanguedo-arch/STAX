# STAX Archive

This archive keeps historical STAX/RAX research, benchmark, campaign, release,
and phase-planning material out of the first user path.

It is provenance, not the public product interface.

The current public docs are:

- `README.md`
- `docs/PRODUCT.md`
- `docs/QUICKSTART.md`
- `docs/CODEX_WORKFLOW.md`
- `docs/PROOF_MODEL.md`
- `docs/COMMANDS.md`
- `docs/STAX_SIDECAR_DOCTRINE.md`

## Folders

- `benchmarks/`: comparison, superiority, external-baseline, and local benchmark
  reports.
- `campaigns/`: old real-use, dogfood, and subscription-comparison campaign
  reports.
- `research/`: learning lab, autonomous improvement lab, legacy RAX specs, and
  old training/memory/mode/policy/safety research docs.
- `releases/`: repo-transfer and release-history reports moved out of the top
  docs path.
- `phase-plans/`: old phase-plan material.

## Not Moved Yet

Some older docs still remain at top level because tests, audits, source prompts,
or local evidence collection read them directly. Move those only after updating
the dependent code or tests.
